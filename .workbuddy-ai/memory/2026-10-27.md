### 踩坑记录

- `jsArray<T>(json)` 是 `inline reified`，**不能传 external interface**（`Cannot pass external interface
  for reified type parameter`）。demo 里要 `jsArray<JsAny?>(json).unsafeCast<Array<MessageListItem>>()`。
- 测试辅助里不要叫 `createUploadFile`：`vaadin.upload.createUploadFile()` 已是 `<vaadin-upload-file>`
  的元素工厂，会重载冲突。上传测试用 `createFile()`（真 `web.file.File`）+
  `createTrackedFile()`（`unsafeCast<UploadFile>`）+ `createFiles(n)`。
- `web.file.File(fileBits: ReadonlyArray<BlobPart>, fileName, FilePropertyBag)` 可直接构造，
  `BlobPart` = `JsAny`，Kotlin String 需 `unsafeCast<BlobPart>()`；`ReadonlyArray` 就是 Kotlin `Array`。
- 本机 Gradle 增量在 S: 网络盘上偶尔不识别改动，`compileTestKotlinJs` 显示 UP-TO-DATE 时加
  `-Dorg.gradle.vfs.watch=false` 或直接看测试报告时间戳确认真的跑了。
- 验证结果：`jsBrowserTest` 1538 个用例 0 失败，`detekt build` 通过，锁文件随修订号重建。
