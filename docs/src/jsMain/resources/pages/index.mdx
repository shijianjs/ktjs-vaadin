<ktjs-features section-title="What it gives you" tinted>

<ktjs-feature icon="lucide:component" title="Typed elements">`createButton { }` returns `ButtonElement`, not `HTMLElement`; the tag tells the compiler what the node is.</ktjs-feature>

<ktjs-feature icon="lucide:tag" title="Typed attributes">`cardTitleAttr` is an `Attribute<String>`, `titleHeadingLevelAttr` an `Attribute<Int>` — read and written through the HTML attribute, decoded by a codec.</ktjs-feature>

<ktjs-feature icon="lucide:palette" title="Typed theme variants">`ButtonVariants.primary` instead of `theme="primary"`; each component owns its legal tokens, and `addTheme` keeps the ones already set.</ktjs-feature>

<ktjs-feature icon="lucide:layers" title="Capabilities, not just classes">Upstream mixins are `external interface`s, so a function can take a `FieldMixin` and accept every component that really has a field.</ktjs-feature>

<ktjs-feature icon="lucide:wrench" title="Lumo utility classes">`LumoUtility.Padding.MEDIUM` mirrors Flow's `LumoUtility` class one to one, checked against `utility.css`.</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="Covered by a demo">Every component has a page that mirrors the upstream documentation — those pages double as the integration tests.</ktjs-feature>

</ktjs-features>
