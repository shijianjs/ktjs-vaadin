<ktjs-features section-title="它给了什么" tinted>

<ktjs-feature icon="lucide:component" title="元素有类型">`createButton { }` 返回 `ButtonElement`，不是 `HTMLElement`——标签告诉编译器这个节点是什么。</ktjs-feature>

<ktjs-feature icon="lucide:tag" title="属性有类型">`cardTitleAttr` 是 `Attribute<String>`，`titleHeadingLevelAttr` 是 `Attribute<Int>`——读写的是 HTML 属性，解码交给 codec。</ktjs-feature>

<ktjs-feature icon="lucide:palette" title="主题变体有类型">写 `ButtonVariants.primary`，而不是 `theme="primary"`；每个组件拥有自己的合法 token，`addTheme` 保留已设置的那些。</ktjs-feature>

<ktjs-feature icon="lucide:layers" title="按能力使用">上游 mixin 是 `external interface`，函数可以直接收 `FieldMixin`，从而接受所有真的带字段的组件。</ktjs-feature>

<ktjs-feature icon="lucide:wrench" title="Lumo 工具类">`LumoUtility.Padding.MEDIUM` 与 Flow 的 `LumoUtility` 逐项对应，并与 `utility.css` 核对过。</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="有 demo 兜底">每个组件都有对应上游文档的页面，这些页面本身就是集成测试。</ktjs-feature>

</ktjs-features>
